# ALMOGHANI SPORT

Arabic, right-to-left sports guide and official-source directory.

## Run

Open `index.html` in a modern browser, or serve this folder with any static web server. The site has no build step or package dependencies.

## Data and broadcasts

This static release does not connect to a live scores or fixtures service. Until verified official data is available, the schedule displays «لا توجد معلومات مؤكدة حاليًا». All event times shown by the page use the `Asia/Riyadh` time zone.

The player does not embed an unverified stream. Use the official-source links to check for an authorized broadcast on the publisher's site.
